# Язык программирования С

_Темы для самостоятельного изучения отмечены курсивом._


**Результаты успешного освоения курса**  
После прохождения вы сможете:  
- Писать, компилировать и отлаживать приложения на С с использованием Visual Studio \ VS Code и _CMake_  
- Использовать массивы, структуры, файлы и связывать модули для построения проектов  
- Управлять памятью через указатели и динамические структуры данных (динамические массивы, списки)  
- Применять ветвления, циклы и функции для решения алгоритмических задач  
- Разрабатывать программы по принципам процедурного и структурного подхода с учётом _тестирования_ и критериев качества кода  
- Легко перейти к изучению С-подобных языков программирования (в том числе С++, Java, C#, javaScript) и парадигмы ООП, опираясь на прочный фундамент С языковых конструкций и методологий программирования.
- Начать использовать язык С для программирования микроконтроллеров (например Arduino).

## 4. Основные алгоритмические конструкции.
1. Условный оператор. *Тернарный оператор*. Примеры. Сравнение вещественных чисел.
1. Оператор выбора. Общий вид. Типы выражения (int, char, ...). default. Несколько case подряд (множественные варианты). Пример с меню. Ошибки с забытым break.

### Циклы 
1. Цикл с предусловием и постусловием; Заголовок и тело цикла. Операторные скобки. Условие и его изменение в цикле.
    1. Примеры: сумма ряда и работа со счётчиком; оптимизация вычислений с использованием предыдущего значения; ввод данных с проверкой; демонстрация выполнения циклов в отладчике; сумма ряда до заданной точности ε.
    1. Частые ошибки: бесконечный цикл, = вместо ==
1. Цикл со счётчиком. Инкремент и декремент. Пример: Таблица квадратов чисел. Изменение шага. Частые ошибки: неправильные условия вида `<` вместо `<=` и наоборот, `;` вместо тела цикла; неизменность переменной цикла.
1. Примеры для циклов: нахождение произведения нескольких множителей; нахождение суммы; поиск минимума\максимума в последовательности [случайных чисел]. Пример вычисления чисел Фибоначчи — пример использования вычислений с предыдущего шага, пример использования пары значений (переменных) для вычисления последовательности длины n.
1. Условный оператор внутри цикла. Пример вычисления кусочной функции. Ввод последовательности до некоторого числа, суммирование положительных элементов последовательности.
1. Циклы и условный оператор. `Break`. `Continue`. Пример с «бесконечным» циклом; обработка последовательного ввода (сумма вводимых значений).
1. Пример вычисления чисел Фибоначчи.
1. Использование отладчика. *Логирование.*
1. Вложенные циклы. Примеры: Таблица умножения. Вложенные суммы.
1. *Примеры: проверка ввода с условием, проверка ввода с циклом, численное интегрирование*


## 5. Массивы
1. Повторение: дерево типов данных.
1. Массивы. Объявление. Тип массива с учётом размера. Размерность и измерения. Индексация и доступ к элементам. Типичные ошибки индексации: индексация не с нуля, выход за пределы массива. Копирование массивов.
1. Примеры: Ввод данных в массив и заполнение. Вывод данных из массива. Вывод по m элементов в строку.
1. Статические (глобальные переменные) и автоматические массивы, VLA (variable length arrays) и их ограниченная поддержка.
1. Практика использования массивов: использование n элементов заранее созданного массива; размер-константа, размер-переменная и размер, объявленный через `#define`. Инициализация массива: `int arr[n] = {1, 2, 3};` и `int arr[3] = {1, 2, 3};`
1. Примеры: алгоритм последовательного поиска, поиска максимума\минимума.
1. Примеры: фильтрация массива (заполнение нового массива числами из исходного).
1. Примеры: Обработка массивов с использованием нескольких элементов. Частые ошибки. Скалярное произведение векторов.
1. Двумерные массивы. Заполнение и вывод двумерных массивов. Примеры: работа со списком координат; перемножение матрицы на вектор и матрицы на матрицу.
1. *Динамические массивы.*

    - *Приведение типов указателей.*
    - *Адресная арифметика*
1. Организация и приёмы работы с одномерными и многомерными динамическими массивами данных.
1. memcpy, memset
1. void*
1. *Примеры*


## 7. Составные типы данных. Файлы
1. Понятие структурированных данных.
    - *Перечисления, объединения*, структуры. Поля. Доступ (оператор .). Примеры структур.
    - Инициализация полей через {}. Инициализация через {} с указанием названий полей. Копирование структур.
    - Функции-инициализаторы. Функции для вывода на экран. Функции для сравнения. sprintf.
    - Объявление структуры через `typedef`.
    - Передача структуры в функции и возврат из функции. Передача: по значению и по ссылке (через указатель). const параметры.
    - Массивы из структур. Примеры: вывод на экран, функции агрегации, проверка значений.
    - sizeof и выравнивание памяти.
    - Массивы внутри структур.

    - Объединения.

1. *Примеры: среднее арифметическое чисел из файла*


## 8. Процедурное программирование
1. Процедурное программирование.
    - Область видимости, время жизни, пространство имен элементов программы. Глобальные и локальные переменные.
    - Принцип «Не повторяй себя». Примеры: функция для арифметических вычислений (ввод и вывод внутри функции) → функция с параметрами и возвращаемым значением.
    - Формальные и фактические параметры.
    - Глобальные и локальные переменные. Побочные эффекты.
    - Передача аргументов по ссылке (указателю) и по значению. Const указатели.
    - Примеры: функция деления с остатком; вывод массива на экран.
    - Массивы и функции: передача статических (`int arr[128]`) и автоматических (Variable Length Array) массивов (`int arr[]`) в функцию. Передача матриц в функцию (`int matr[][N]`).
    - Принцип единственной ответственности. Повторное использование функции.
    - Объявление и определение функций.
    - Проверка предусловия функции. Возврат кода ошибки \ логического значения.
    - Документирующие комментарии.
    - Частые ошибки: вывод на экран вместо возврата значения, считывание значения из стандартного ввода вместо передачи параметров в функцию, использование глобальных переменных, вызов до объявления.
    - Примеры декомпозиции программы на функции. Вычислить среднее арифметическое положительных чисел и количество отрицательных. Работа с массивами.
1. Автоматическое тестирование функций. Assert.
1. *Библиотеки Unity и Check для модульного тестирования.*
1. *Указатели на функции*
