# Компиляция, запуск и отладка C-программ в Zed

## 1. Сборка (компиляция)

### Быстрый способ — через терминал

```sh
clang -std=c23 -Wall -Wextra -g main.c -o main
./main
```

Разбираем флаги:

| Флаг | Назначение |
|------|-----------|
| `-std=c23` | Стандарт языка C23 (можно `-std=c17` / `-std=c11`) |
| `-Wall -Wextra` | Предупреждения о потенциальных ошибках |
| `-g` | Добавить отладочную информацию (нужна для отладчика) |
| `-o main` | Имя выходного файла |
| `-lm` | Подключить математическую библиотеку (`math.h`) |

### Через задачу (Task) в Zed

Нажмите **`Ctrl+Shift+P`** / **`Cmd+Shift+P`** → выберите **Tasks: Run** → **Build current C file**.

Результат (исполняемый файл) появится рядом с исходным `.c` файлом.

### Собрать и сразу запустить

В том же меню выберите **Build and run current C file**. Программа выполнится, вывод появится в панели терминала внизу.

## 2. Настройка задач (`.zed/tasks.json`)

Создайте в корне проекта папку `.zed/` с файлом `tasks.json`:

```jsonc
// .zed/tasks.json
[
  {
    "label": "Build current C file",
    "command": "clang",
    "args": [
      "-lm",
      "-std=c23",
      "-Wall",
      "-Wextra",
      "-g",
      "$ZED_FILE",
      "-o",
      "$ZED_DIRNAME/$ZED_STEM"
    ],
    "cwd": "$ZED_WORKTREE_ROOT",
    "tags": ["build"]
  }
]
```

### Полезные переменные Zed

| Переменная | Что означает |
|-----------|-------------|
| `$ZED_FILE` | Полный путь к текущему файлу |
| `$ZED_DIRNAME` | Папка текущего файла |
| `$ZED_STEM` | Имя файла без расширения |
| `$ZED_WORKTREE_ROOT` | Корень проекта (папка с `.git` или корень) |

## 3. Отладка (Debug)

### Предварительные требования

Установите **Code LLDB**:

- **Zed → Extensions** → найдите **CodeLLDB** → **Install**
- Или в палитре команд: **`Ctrl+Shift+P`** → **zed: extensions** → CodeLLDB

### Настройка отладки (`.zed/debug.json`)

```jsonc
// .zed/debug.json
[
  {
    "label": "Debug current C file",
    "adapter": "CodeLLDB",
    "request": "launch",
    "program": "$ZED_DIRNAME/$ZED_STEM",
    "cwd": "$ZED_DIRNAME",
    "build": "Build current C file"
  }
]
```

> **Важно:** Перед отладкой файл должен быть собран с флагом `-g`.

### Как запустить отладку

1. Откройте `.c` файл.
2. **`Ctrl+Shift+P`** → **Debug** (или кнопка ▶️ в левом нижнем углу).
3. Выберите **Debug current C file**.

### Управление отладкой

| Действие | Горячая клавиша |
|---------|----------------|
| Продолжить (Continue) | `F5` |
| Шаг с заходом (Step Into) | `F11` |
| Шаг с обходом (Step Over) | `F10` |
| Шаг с выходом (Step Out) | `Shift+F11` |
| Точка остановки (Toggle breakpoint) | Клик слева от номера строки |
| Остановить отладку | `Shift+F5` |

### Что можно делать в отладчике

- **Точки остановки** — кликните левее номера строки.
- **Смотреть переменные** — панель Variables показывает их значения.
- **Watch** — можно добавить выражение для наблюдения (например, `sum`).
- **Стек вызовов** — показывает, в какой функции вы находитесь.

```

├── main.c              # исходный код
├── .zed/

│   └── debug.json      # конфигурация отладчика

```

## 5. Типичные проблемы

| Симптом | Что делать |
|---------|-----------|
| `clang: command not found` | Установите компилятор: `sudo apt install clang` (Ubuntu) / `brew install llvm` (macOS) |
| `Unable to find executable` | Сначала выполните сборку (Build) — программа ещё не скомпилирована |
| `No symbols loaded` | Забыли флаг `-g` при компиляции |
| `CodeLLDB not found` | Установите расширение CodeLLDB в Zed |
| Программа запускается, но нет вывода в Debug | Используйте задачу **Build and run** или запускайте из терминала |

---

## 6. Кратко: последовательность действий для новой программы

1. Написали `.c` файл.
2. **`Ctrl+Shift+P`** → **Tasks: Run** → **Build current C file**.
3. **`Ctrl+Shift+P`** → **Tasks: Run** → **Build and run current C file** — проверить вывод.
4. Если нужно отладить: расставьте точки остановки, **`Ctrl+Shift+P`** → **Debug**.
