# Передача аргументов по ссылке (через указатель)

## 1. Проблема: одного `return` мало

Функция в C может вернуть **только одно** значение через `return`.

Предположи, что нужно сделать функцию, которая делит два целых числа и возвращает и **частное**, и **остаток**. С помощью `return` можно вернуть только что-то одно:

```c
int divide_quot(int a, int b) {
    return a / b;
    // return a/b, a%b; // так нельзя, вернётся только последнее значение
}
```

Проблему можно решить несколькими способами, но не все они уместны здесь и не все они хорошие:

- Использовать глобальную переменную, например `int rem;` и записывать остаток в неё. Но использование глобальных переменных создаёт побочный эффект у функции, а их стоит избегать. Нельзя будет сделать два вызова функции подряд.
- Сделать две отдельные функции `getQuot`/`getRem`. Но тогда деление будет выполняется дважды. 
- Создать отдельную структуру данных, которая будет хранить два значения. Возвращать переменную этого типа. Неплохой вараинт, но избыточно для данного простого случая.

Нужен механизм, позволяющий функции **изменять переменные из вызывающего кода**.



## 2. Идея: передаём адрес, а не значение

В C у каждой переменной есть **адрес** в памяти. Вместо того чтобы копировать значение переменной в параметр функции, можно передать **указатель на неё** — то есть её адрес.

Тогда функция сможет «заглянуть» по этому адресу и записать туда новое значение.

```c
#include <stdio.h>

void divide(int a, int b, int *quot, int *rem) {
    *quot = a / b;   // записать частное по адресу, хранящемуся в quot
    *rem  = a % b;   // записать остаток по адресу, хранящемуся в rem
}

int main(void) {
    int x, y;
    divide(13, 5, &x, &y);
    printf("13 / 5 = %d (ост. %d)\n", x, y);   // 13 / 5 = 2 (ост. 3)
    return 0;
}
```

### Ключевые элементы

| Символ | Название | Смысл в этом контексте |
|---|---|---|
| `int *quot` | Параметр-указатель | «quot хранит **адрес** переменной типа int» |
| `*quot = …` | Разыменование | «записать значение **по адресу**, который лежит в quot» |
| `&x` | Взятие адреса | «передай не значение x, а **адрес**, где x находится» |

---

## 3. Важное уточнение: в C всё передаётся по значению

В C **любой** аргумент передаётся по значению. Когда мы пишем `divide(13, 5, &x, &y)`, в параметры `quot` и `rem` копируются **значения адресов** переменных `x` и `y`. Сами адреса — это просто числа (например, `0x7fff..12`). Функция не может изменить то, **куда** указывает `quot`, но она может изменить то, **что лежит по адресу** `quot`.

Таким образом, **«передача по ссылке» в C — это имитация через указатели**: мы передаём значение-адрес и разыменовываем его внутри функции.

## 4. Примеры

### 4.1. Обмен значений (swap)

```c
void swap(int *pa, int *pb) {
    int tmp = *pa;
    *pa = *pb;
    *pb = tmp;
}

int a = 5, b = 9;
swap(&a, &b);
// теперь a = 9, b = 5
```

### 4.2. Поиск минимума и максимума в массиве

```c
void minMax(const int arr[], int n, int *min, int *max) {
    *min = *max = arr[0];
    for (int i = 1; i < n; ++i) {
        if (arr[i] < *min) *min = arr[i];
        if (arr[i] > *max) *max = arr[i];
    }
}

int data[] = {3, 7, 1, 9, 4};
int mn, mx;
minMax(data, 5, &mn, &mx);
// mn = 1, mx = 9
```

### 4.3. Функция ввода значения

```c
void inputInt(const char *prompt, int *value) {
    printf("%s", prompt);
    scanf("%d", value);   // value уже содержит адрес — & не нужен
}

int age;
inputInt("Введите возраст: ", &age);
```

## 5. Константные указатели в параметрах

Если функция не должна изменять данные по указателю, используйте `const`:

```c
void printArray(const int *arr, int size) {
    for (int i = 0; i < size; ++i)
        printf("%d ", arr[i]);
}
```

Ключевое слово `const` защищает от случайной записи и служит документацией: «я не буду менять ваши данные».

| Сигнатура | Значение |
|---|---|
| `int *p` | Данные можно читать и изменять |
| `const int *p` | Данные можно только читать (указатель на константу) |
| `int * const p` | Сам указатель нельзя перенаправить (константный указатель, редкий в параметрах) |

## 6. Передача массивов — неявная передача по ссылке

В C имя массива — это адрес его первого элемента. Поэтому массивы **всегда** передаются по ссылке (копия не создаётся):

```c
void fillZero(int arr[], int n) {     // эквивалентно: int *arr
    for (int i = 0; i < n; ++i)
        arr[i] = 0;                   // arr[0] — то же самое, что *arr
}

int a[100];
fillZero(a, 100);                     // a — уже адрес, & не нужен
```

Записи `int arr[]` и `int *arr` в параметрах функций — одно и то же. Первая форма подчёркивает, что ожидается массив, вторая — что ожидается указатель.

## 7. Типичные ошибки

### ❌ Забыли `&` при вызове

```c
swap(a, b);   // передаются значения 5 и 9, а не их адреса
```

Функция получит адреса `5` и `9` — скорее всего, произойдёт **segmentation fault**.

### ❌ Забыли `*` внутри функции

```c
void swap(int *pa, int *pb) {
    int *tmp = pa;   // меняются адреса, а не значения
    pa = pb;
    pb = tmp;
}
```

Переменные в `main` не изменятся.

### ❌ Разыменование нулевого указателя

```c
void setZero(int *p) {
    *p = 0;   // если p == NULL — undefined behavior (краш)
}
```

Перед разыменованием стоит проверять указатель, если он мог прийти извне:

```c
void setZero(int *p) {
    if (p != NULL)
        *p = 0;
}
```

### ❌ Путаница между `int *p` и `int arr[]`

```c
void printSize(int arr[]) {
    printf("%zu\n", sizeof(arr));   // размер указателя (8 или 4 байта), а не массива!
}
```

Внутри функции `sizeof(arr)` даёт размер указателя, а не массива.

---

## 8. Стиль и рекомендации

- **Если функция не меняет данные** — передавайте по значению (для простых типов) или через `const`-указатель (для массивов/структур).
- **Если функция должна изменить аргумент** — передавайте указатель.
- **Параметры-указатели, которые не могут быть `NULL`**, можно не проверять — это ответственность вызывающего.
- **Документируйте** в комментариях, что функция делает с каждым параметром:

```c
/**
 * Делит a на b и возвращает частное и остаток через параметры.
 *
 * @param a   делимое
 * @param b   делитель
 * @param[out] quot  частное
 * @param[out] rem   остаток
 * @pre  b != 0
 * @pre  quot != NULL, rem != NULL
 */
void divide(int a, int b, int *quot, int *rem);
```

---

## 9. *Сравнение с C++ (для общего кругозора)

В C++ есть **настоящие ссылки** (`int &ref = a;`), которые не требуют оператора `*` и конструции `&` при вызове:

```cpp
void divide(int a, int b, int &quot, int &rem) {
    quot = a / b;
    rem  = a % b;
}

divide(13, 5, x, y);   // никаких &, никаких *
```

В C такого синтаксиса нет — только явная работа с указателями.

## 10. Резюме

| Тезис | Формулировка |
|---|---|
| Проблема | `return` возвращает только одно значение |
| Решение | Передаём **адрес** переменной через указатель |
| Внутри функции | Разыменовываем указатель (`*p`) для чтения/записи |
| При вызове | Берём адрес (`&var`) обычной переменной |
| Массивы | Всегда передаются по ссылке (имя массива — это адрес) |
| Защита | `const`-указатель, если данные только читаются |
| Ошибки | Забытые `&`, забытые `*`, NULL, `sizeof` указателя |
